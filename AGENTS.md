# Project Goal

Solve the workshop described in `taller.md` (PWA Security) by implementing all activities in `solucion.html`.

The app is deployed on vercel with the link: barberstudio-bm.vercel.app

## Instructions

- Download any required images into `images/` inside this project directory.
- Take screenshots of each implementation step and save them into `images/`.
- Keep all screenshots — they will be embedded in `solucion.html` as evidence for the final report.

## Activities to implement (from taller.md)

1. Apply digital certificates (SSL/TLS) to the PWA.
2. Validate and sanitize form input fields.
3. Implement Content Security Policy (CSP):
   - Control resource loading to prevent XSS.
   - Control resource types (JS, CSS, images, etc.).
   - Block a specific object.
   - Use hashes to ensure the origin of a specific script.
   - Apply scheme-based or location-based policies for a specific object.
   - Apply strict CSP (strict-dynamic).
4. Enforce HTTPS for all application resources.
